# My Website

This project is a simple website that includes a link to a Facebook profile.

## Project Structure

- `index.html`: The main HTML document for the website.
- `styles.css`: Contains the CSS styles for the website.
- `script.js`: Contains JavaScript code for interactive features.
- `README.md`: Documentation for the project.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open `index.html` in a web browser to view the website.
3. Customize the styles in `styles.css` as needed.
4. Add any JavaScript functionality in `script.js`.
